# Original SDK usage

Start with the complete [API quick start](/api/quick-start), which reads a synthetic IDE configuration through `JetBrains` and shows its actual output.

For project-specific settings, mappings and discovery, continue with [discovery and projects](/guide/discovery), [deployments](/guide/deployments) and [settings example](/api/settings-example). Use the optional [Portline bridge](/guide/portline) for normalized profiles and guarded writing.

For an explicit live operation after selecting a profile, use [the shared connection walkthrough](/api/integration). Native-only execution requirements are represented as `unsupportedOptions`; reading a profile does not grant permission to discard them.
